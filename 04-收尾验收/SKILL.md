## 执行步骤

### Step 1：移交确认

**① AI生成移交检查清单**
AI根据前序阶段所有输出，生成完整的移交检查清单，格式见📂§7-移交检查清单。

**② AI检查移交完整性**
逐项检查交付物是否齐全，标记缺失项。

**③ 用户组织移交确认**
用户与甲方确认所有交付物，甲方在移交确认书上签字，格式见📂§1-移交确认书模板。

### Step 2：合同结算

AI根据合同条款和变更记录，生成结算分析表：

```
原合同金额：[XX]万元
已支付：[XX]万元
变更费用：[XX]万元（[XX]次变更）
应结算总金额：[XX]万元
待支付尾款：[XX]万元

付款条件检查：
✅/❌ 终验确认书已签字
✅/❌ 移交清单已确认
✅/❌ 发票已开具
```

用户根据结算分析，走公司内部结算流程。

### Step 3：项目绩效评价

AI从全项目数据中提取关键指标，对比初期目标和实际结果，格式见📂§2-项目绩效报告模板：

```
指标       目标（计划）    实际          达成率
进度      [日期]交付     [日期]交付     [延期/提前XX天]
成本      [XX]万元      [XX]万元       [XX]%
范围      [XX]个功能点   [XX]个功能点   [XX]%
质量      测试通过率≥95%  [XX]%        达标/不达标
客户满意度  ≥90分        [XX]分        达标/不达标
```

用户根据绩效报告，完成项目绩效评价。

### Step 4：项目复盘

**① AI生成复盘数据报告**
AI从全项目数据中提取关键事件时间线、风险发生情况、变更统计。

**② AI生成复盘会议方案**
建议议程（90分钟）：
1. 项目数据回顾（10分钟）
2. 做得好的（20分钟）
3. 做得不好的（20分钟）
4. 关键决策复盘（20分钟）
5. 经验教训提炼（15分钟）
6. 后续行动（5分钟）

**③ 复盘会执行**
用户组织复盘会，会后把讨论内容发给AI。AI整理成复盘报告，格式见📂§3-复盘报告模板。

**④ AI沉淀经验教训**
将经验教训按类型分类（技术类/管理类/沟通类），存入知识库，格式见📂§6-经验教训知识库模板。

### Step 5：归档

AI检查所有阶段的文档完整性，整理成项目档案目录，存入飞书知识库+本地知识库。

```
项目档案：XX项目（最终版）
├── 00-启动建档/（8份文档）
├── 01-需求管理/（6份文档+会议纪要）
├── 02-技术交底与过程管理/（设计文档+周报+风险登记册）
├── 03-测试与验收/（测试报告+初验报告+终验报告）
└── 04-收尾验收/（移交确认书+绩效报告+复盘报告+关闭确认书）
```

### Step 6：项目关闭

**① AI生成项目关闭检查清单**
检查所有关闭条件是否满足，格式见📂§4-项目关闭确认书模板。

**② 资源释放**
确认团队成员已释放、设备已归还、账号已注销（参考📂§4-项目关闭确认书模板中的资源释放检查项）。

**③ 正式关闭**
所有签字完成，项目正式关闭。AI输出客户满意度评价，格式见📂§5-客户满意度评价模板。
