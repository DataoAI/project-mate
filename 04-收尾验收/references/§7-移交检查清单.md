# §7 移交检查清单

> 用途：04-Step 1检查移交完整性时使用

---

## 移交检查清单

### 软件交付物

- [ ] 系统安装包/部署包（版本号：[版本]）
- [ ] 源代码（含版本标签）
- [ ] 数据库脚本（初始化脚本、迁移脚本）
- [ ] 接口文档（API文档、调用示例）
- [ ] 部署文档（环境要求、部署步骤、配置说明）
- [ ] 用户手册（操作指南、常见问题）
- [ ] 运维手册（监控、备份、故障处理）
- [ ] 测试报告（单元测试、系统测试、压力测试）

### 硬件交付物

- [ ] 服务器/设备清单（型号、配置、序列号）
- [ ] 设备验收单（甲方签字确认）

### 文档交付物

- [ ] 需求规格说明书（冻结版）
- [ ] 详细设计文档
- [ ] 概要设计文档
- [ ] 数据库设计文档
- [ ] 培训材料（操作培训、运维培训）
- [ ] 项目档案（所有阶段文档的最终版本）

### 管理交付物

- [ ] 变更跟踪表（最终版）
- [ ] 风险登记册（最终版）
- [ ] 周报/月报汇总
- [ ] 会议纪要汇总
