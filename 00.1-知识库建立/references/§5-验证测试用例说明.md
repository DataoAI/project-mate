# §5 验证测试用例说明

> 用途：Step 7验证检索时使用

---

## 默认测试用例

| 用例 | 查询内容 | 期望结果 | 通过标准 |
|:----|:--------|:--------|:--------|
| 1 | "合同范围是什么" | 返回合同中关于范围的条文 | 返回内容与合同范围相关 |
| 2 | "用户登录功能要求" | 返回产品说明中关于登录的描述 | 返回内容与用户登录相关 |
| 3 | "数据库设计规范" | 返回技术架构中关于数据库的内容 | 返回内容与数据库设计相关 |

## 验证方法

```python
def verify_knowledge_base(collection, test_cases):
    """
    验证知识库检索效果
    
    参数：
        collection: Chroma集合
        test_cases: 测试用例列表，每项为(query, expected_description)
    返回：
        results: 每项测试的结果
    """
    results = []
    passed = 0
    
    for query, expected in test_cases:
        query_result = collection.query(
            query_texts=[query],
            n_results=3
        )
        
        docs = query_result['documents'][0]
        distances = query_result['distances'][0]
        
        print(f"查询: '{query}'")
        print(f"期望: {expected}")
        print(f"返回 {len(docs)} 条结果:")
        for i, (doc, dist) in enumerate(zip(docs, distances)):
            print(f"  [{i+1}] 距离={dist:.4f} | {doc[:100]}...")
        
        # 人工判断是否通过
        user_input = input("此用例是否通过？(y/n): ")
        if user_input.lower() == 'y':
            passed += 1
            results.append(True)
        else:
            results.append(False)
        print()
    
    print(f"通过率: {passed}/{len(test_cases)}")
    return results
```

## 验证通过标准

| 条件 | 结果 |
|:----|:----|
| 3个测试用例全部通过 | ✅ 知识库可用 |
| 2个测试用例通过 | ✅ 知识库可用（标注未通过的用例） |
| 0-1个测试用例通过 | ❌ 知识库不可用，检查分块或标签后重建 |
