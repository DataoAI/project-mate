# §3 标签体系说明

> 用途：Step 6添加metadata时使用

---

## 两层标签

### 第一层：来源类型

| 标签 | 说明 | 来源文档 |
|:----|:----|:---------|
| 招标 | 来自招标文件/标书 | 招标文件、技术规范书 |
| 合同 | 来自合同条款 | 合同、补充协议 |
| 产品 | 来自产品说明书/手册 | 产品手册、用户手册 |
| 技术 | 来自技术架构文档 | 技术方案、架构设计 |
| 历史项目 | 来自历史项目资料 | 历史项目文档、复盘报告 |
| 交底会 | 来自交底会纪要 | 会议纪要、交底记录 |
| 建议书 | 来自项目建议书 | 可行性方案、建议书 |

### 第二层：主题

由AI根据内容自动生成，如：
- 用户管理
- 验收标准
- 报表功能
- 数据库设计
- 接口规范
- 权限控制
- 部署方案

## metadata格式

```python
metadata = {
    "source_type": "招标",       # 第一层：来源
    "topic": "用户管理",         # 第二层：主题
    "project": "XX项目",         # 项目名称
    "doc_name": "招标文件.docx",  # 原文档名称
    "chunk_index": 0             # 块序号
}
```

## 检索优先级

1. 先按来源类型筛选（`where={"source_type": "合同"}`）
2. 再按主题关键词匹配（`query_texts`）
3. 两层叠加提高精度
