# §2 分块规则参考

> 用途：Step 5文档分块时使用

---

## 核心原则

**"一个主题的完整说明"= 一块**

不是按字数切，是按**主题完整性**切：
- 招标文件：按章节切（"用户管理功能"章节 = 一块）
- 合同：按条款组切（"验收标准条款组" = 一块）
- 产品说明书：按功能模块切（"报表功能模块" = 一块）

## 分块大小

| 指标 | 值 | 理由 |
|:----|:--|:----|
| 每块大小 | 1000-4000字 | 太大浪费token，太小没有上下文 |
| 每块平均 | 2000-3000字 | 最佳平衡点 |

## 分块方法

```python
def split_by_topic(doc, max_chunk_size=4000, min_chunk_size=1000):
    """
    按主题分块，每块在min_chunk_size和max_chunk_size之间
    
    参数：
        doc: 文档全文
        max_chunk_size: 每块最大字数
        min_chunk_size: 每块最小字数
    返回：
        chunks: 分块列表
    """
    chunks = []
    current_chunk = ""
    
    # 按段落分割（假设段落由空行分隔）
    paragraphs = [p for p in doc.split("\n\n") if p.strip()]
    
    for paragraph in paragraphs:
        # 如果当前块+新段落超过最大字数，先保存当前块
        if len(current_chunk) + len(paragraph) > max_chunk_size:
            if current_chunk and len(current_chunk) >= min_chunk_size:
                chunks.append(current_chunk.strip())
                current_chunk = paragraph
            elif current_chunk:
                # 当前块还不到最小字数，继续追加
                current_chunk += "\n\n" + paragraph
            else:
                # 当前块为空，新段落直接作为开始
                current_chunk = paragraph
        else:
            current_chunk += "\n\n" + paragraph
    
    # 保存最后一块
    if current_chunk.strip() and len(current_chunk.strip()) >= min_chunk_size * 0.5:
        chunks.append(current_chunk.strip())
    elif current_chunk.strip():
        # 最后一块太小，合并到上一块
        if chunks:
            chunks[-1] += "\n\n" + current_chunk.strip()
        else:
            chunks.append(current_chunk.strip())
    
    return chunks
```
