# §7 阶段核查Base表字段说明

> 用途：Step 9创建阶段核查Base表时使用

---

## 阶段核查Base表（5条记录，6字段）

| 字段 | 类型 | 说明 |
|:----|:----|:------|
| 阶段编号 | 文本 | 00/01/02/03/04 |
| 阶段名称 | 文本 | 如"项目启动建档" |
| 状态 | 单选 | 待开始/进行中/已完成/已跳过 |
| 完成日期 | 日期 | 实际完成日期 |
| 核查人 | 用户 | 项目经理 |
| 备注 | 多行文本 | 核查说明 |
