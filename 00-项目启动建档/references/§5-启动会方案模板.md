# §5 启动会方案模板

> 用途：Step 11输出启动会方案时使用

---

## 项目启动会方案

### 建议议程（60-90分钟）

| 环节 | 时长 | 内容 | 负责人 |
|:----|:----|:-----|:------|
| 项目背景介绍 | 10分钟 | 项目为什么做、目标是什么 | 项目经理 |
| 范围与目标确认 | 15分钟 | 做什么、不做什么、验收标准 | 项目经理 |
| 里程碑计划 | 15分钟 | 各阶段时间节点、交付物 | 项目经理 |
| 角色与职责 | 10分钟 | 谁负责什么、沟通机制 | 项目经理 |
| 技术方案概述 | 10分钟 | 技术路线、架构设计 | 技术负责人 |
| 风险讨论 | 10分钟 | 已知风险、应对策略 | 全体 |
| 讨论与确认 | 15分钟 | 自由讨论、问题解答 | 全体 |

### 建议参会人员

| 角色 | 必要性 | 说明 |
|:----|:-----|:----|
| 项目经理 | 必须 | 主持 |
| 项目总监 | 必须 | 决策支持 |
| 甲方代表 | 必须 | 确认范围 |
| 技术负责人 | 必须 | 技术方案 |
| 产品经理 | 建议 | 需求理解 |
| 监理 | 按需 | 流程监督 |
| 核心开发人员 | 建议 | 技术理解 |

### 启动会前准备

- [ ] 项目章程已生成（发给参会人预读）
- [ ] 里程碑计划已生成
- [ ] 干系人登记表已确认
- [ ] 会议室/飞书会议已预定
- [ ] 会议材料已准备

### 启动会后事项

- [ ] 会议纪要整理并发送
- [ ] 项目章程签字确认
- [ ] 进入01-需求管理阶段
