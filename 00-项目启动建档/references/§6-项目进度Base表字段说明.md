# §6 项目进度Base表字段说明

> 用途：Step 9创建项目进度Base表时使用

---

## 项目进度Base表（13字段）

| 字段 | 类型 | 说明 |
|:----|:----|:------|
| 任务编号 | 文本 | 自动生成，如T-001 |
| 任务名称 | 文本 | 任务描述 |
| 所属阶段 | 单选 | 00-启动建档/01-需求管理/02-技术交底/02-过程管理/03-测试验收/04-收尾验收 |
| 负责人 | 用户 | 从飞书通讯录选择 |
| 计划开始 | 日期 | 计划开始时间 |
| 计划结束 | 日期 | 计划结束时间 |
| 实际开始 | 日期 | 实际开始时间 |
| 实际结束 | 日期 | 实际结束时间 |
| 状态 | 单选 | 待开始/进行中/已完成/已延期/已取消 |
| 完成度 | 百分比 | 0-100% |
| 优先级 | 单选 | P0-必须/P1-应该/P2-可选 |
| 备注 | 多行文本 | 补充说明 |
| 关联交付物 | 文本 | 关联的交付物链接 |
